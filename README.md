# 🌱 NaturaleBites

> A food-sharing platform designed to reduce food waste and connect surplus food with people in need.

## 🌐 Live Demo

🔗 https://task02-app-site.web.app/

## 📌 About the Project

NaturaleBites is a web-based food-sharing platform that promotes food donation and helps reduce unnecessary food waste.

The platform provides a simple interface where users can explore food-related information and support the idea of sharing surplus food with people who need it.

## ✨ Key Features

- ✅ Clean and responsive user interface
- ✅ Food sharing and donation concept
- ✅ Food category-based presentation
- ✅ User-friendly navigation
- ✅ Firebase integration
- ✅ Deployed as a live web application
- ✅ Mobile-friendly design
- ✅ Organized and maintainable project structure
